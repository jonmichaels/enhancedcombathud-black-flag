# Argon - Combat HUD (BLACKFLAG)

Tales of the Valiant (ToV) / Black Flag system integration for the [Argon Combat HUD](https://github.com/theripper93/enhancedcombathud).

Ported from the [D&D 5E plugin](https://github.com/theripper93/enhancedcombathud-dnd5e).

## Requirements

- [Argon - Combat HUD (CORE)](https://github.com/theripper93/enhancedcombathud) v3.0.4+
- [Black Flag Roleplaying](https://github.com/koboldpress/black-flag) v2.0.0+
- Foundry VTT v13+

## Development

Developed in `~/projects/enhancedcombathud-black-flag/` with a symlink into Foundry userdata for live testing.

```bash
cd ~/projects/enhancedcombathud-black-flag
# symlink: ~/foundryuserdata/Data/modules/enhancedcombathud-black-flag -> ~/projects/enhancedcombathud-black-flag
```
